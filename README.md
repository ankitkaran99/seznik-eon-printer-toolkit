# Seznik EON Printer Toolkit

Toolkit for printing to supported 57mm BLE thermal printers over Bluetooth, with an optional print relay. Supports **Windows** and **Linux** (Debian/Ubuntu/Raspbian).

## What It Does

- Scans for a compatible BLE printer and saves its config
- Prints text, images, PDFs, and test pages directly over BLE
- Creates a print relay (Windows printer queue or Linux CUPS queue) that forwards jobs to the BLE printer over a local TCP socket

## Repository Layout

- `bt_scan.py`: BLE scanner and printer config saver
- `bt_print.py`: direct BLE printing
- `printer_relay.py`: local TCP relay for print spool jobs
- `printer_gui.py`: GUI for scan and print operations (Windows)
- `configure_relay_printer.ps1`: full Windows relay setup and uninstall script
- `setup_linux.sh`: full Linux setup script (deps, relay service, CUPS)
- `fix_bluez_le.sh`: generated by setup — fixes BlueZ transport issues on Linux
- `launch.vbs`: launches the GUI without a console window (Windows)
- `drivers\`: bundled printer driver package used by Windows relay setup

## Linux

### Quick Start

```bash
sudo bash setup_linux.sh
```

That script handles everything:

1. Installs system packages (`bluez`, `python3`, `poppler-utils`, `ghostscript`, `cups`)
2. Creates a Python virtualenv and installs required packages (`bleak`, `pillow`, `pypdf2`, `pdfplumber`)
3. Enables BlueZ experimental mode (required for reliable LE transport)
4. Scans for the printer and saves config
5. Installs `eon-printer-relay` as a systemd service (auto-starts on boot)
6. Registers a CUPS printer queue pointing at the relay (`BT-Thermal-Printer`)
7. Installs an `eon-print` CLI wrapper available system-wide

After setup, keep the toolkit directory in place — the relay service and CLI wrapper reference it.

### CLI Usage

```bash
eon-print --test-page
eon-print --print-text "Hello"
eon-print --print-image photo.jpg
eon-print --print-pdf file.pdf
```

Or directly via the virtualenv:

```bash
.venv/bin/python bt_scan.py --save
.venv/bin/python bt_print.py --test-page
```

### Relay Service

The relay listens on `127.0.0.1:9100` by default and forwards incoming print jobs to the BLE printer.

```bash
systemctl status eon-printer-relay
journalctl -u eon-printer-relay -f
```

Custom port:

```bash
RELAY_PORT=9200 sudo bash setup_linux.sh
```

Or edit `/etc/systemd/system/eon-printer-relay.service` and restart:

```bash
sudo systemctl daemon-reload
sudo systemctl restart eon-printer-relay
```

### Re-scanning the Printer

If the printer MAC changes or you replace the printer:

```bash
.venv/bin/python bt_scan.py --save
```

### BlueZ Transport Fix

Some BLE printers (including JieLi/JL chipset devices such as the P1 series) advertise themselves as dual-mode Bluetooth devices. BlueZ on Linux interprets this as a BR/EDR device and refuses LE connection with `BREDR.ProfileUnavailable`.

`setup_linux.sh` generates `fix_bluez_le.sh` to resolve this. Run it if scanning fails:

```bash
sudo bash fix_bluez_le.sh
```

It auto-discovers the printer MAC via a BLE scan, writes a BlueZ device info file that forces LE transport, and locks it so BlueZ cannot overwrite it during discovery. Then re-run the scan:

```bash
.venv/bin/python bt_scan.py --save
```

If you know the printer MAC already:

```bash
sudo bash fix_bluez_le.sh AA:BB:CC:DD:EE:FF
```

After a successful scan you can unlock the file:

```bash
sudo chattr -i /var/lib/bluetooth/<adapter_mac>/<printer_mac>/info
```

### Linux Requirements

- Debian 12+, Ubuntu 22.04+, or Raspbian (Bookworm+)
- BlueZ 5.65+
- Python 3.11+
- A supported BLE receipt printer powered on and in advertising mode

## Windows

### Quick Start

If you want a normal Windows printer that forwards to the BLE printer, run as Administrator:

```powershell
powershell -ExecutionPolicy Bypass -File configure_relay_printer.ps1
```

That script handles the full setup:

1. Resolves a system Python install, or installs one with `winget` if it is missing
2. Installs required Python packages into that system Python
3. Prompts for BLE printer scan and saves printer config
4. Installs or reuses the printer driver
5. Creates or rebinds the Windows printer queue
6. Registers the relay at logon
7. Creates Desktop and Start Menu shortcuts for the GUI launcher

After installation, do not delete this toolkit directory. Keep it in a persistent location because the relay launcher, shortcuts, and supporting files continue to run from this directory.

### GUI Usage

Launch the GUI:

```text
launch.vbs
```

Or run it directly with Python if needed:

```powershell
python printer_gui.py
```

Typical GUI flow:

1. Power on the printer and put it into advertising mode
2. Click `Scan`
3. Save the detected printer config
4. Print text, an image, a PDF, or a test page

### CLI Usage

```powershell
python bt_scan.py --save
python bt_print.py --test-page
python bt_print.py --print-text "Hello"
python bt_print.py --print-image photo.jpg
python bt_print.py --print-pdf file.pdf
```

Use PDFs designed for 57mm paper width.

### Relay Setup

Default relay target: `127.0.0.1:9100`

Setup creates:

- A saved BLE printer config
- A local TCP/IP printer port
- A Windows printer queue bound to that port
- A logon startup launcher for `printer_relay.py`
- Desktop and Start Menu shortcuts to `launch.vbs`
- User environment variables used by the launchers

Common options:

```powershell
# Specify driver name manually
powershell -ExecutionPolicy Bypass -File configure_relay_printer.ps1 `
  -DriverName "POS-58 Series"

# Override Python path or relay script path
powershell -ExecutionPolicy Bypass -File configure_relay_printer.ps1 `
  -PythonExecutablePath "C:\Python312\python.exe" `
  -RelayScriptPath "printer_relay.py"

# Custom relay port
powershell -ExecutionPolicy Bypass -File configure_relay_printer.ps1 `
  -RelayPort 9200
```

### Relay Uninstall

```powershell
powershell -ExecutionPolicy Bypass -File configure_relay_printer.ps1 -Uninstall
```

Removes the startup launcher, Desktop and Start Menu shortcuts, relay printer queue, relay TCP/IP port, and user environment variables. Does not remove the toolkit files, installed Python, or the printer driver package.

### Manual Relay Start

```powershell
python printer_relay.py
python printer_relay.py --port 9200
```

## Notes

- Printer config is stored in the user profile (`~/.seznik-eon-printer-toolkit/bt_printer_config.json`) so all scripts share the same saved printer
- Do not delete the toolkit directory after setup; keep it somewhere persistent
- If you move the toolkit directory, rerun the setup script so service paths and shortcuts are refreshed
- PDFs should be designed for 57mm (384 dot) paper width for best results
